用大疆 RC-N3 打 PC 游戏 Play PC games with your DJI RC-N3

dji-rc-bridge reads a DJI RC-N3 drone remote over USB serial using the undocumented DUML protocol and republishes it as a virtual Xbox 360 controller. Any game that supports a gamepad just works — no DLL injection, no patches. dji-rc-bridge 通过 USB 串口、用无公开文档的 DUML 协议读取大疆 RC-N3 遥控器的输入，并把它重新发布成一台虚拟 Xbox 360 手柄。支持手柄的游戏可以直接玩——不注入 DLL、不打补丁。

Quick start快速开始

Four commands from the download to in-game. 四条命令，从下载到进游戏。

Plug into the charge / tuning USB-C port.请插在"充电/调参"USB-C 口上。 The phone socket makes the remote act as a USB host and it will fail to enumerate. Install the ViGEmBus driver once, and the DJI VCOM driver (shipped with DJI Assistant 2 Consumer) if you want the ports named properly. 接手机的口会让遥控器变成 USB 主机、导致枚举失败。另外需装一次 ViGEmBus 驱动；若希望端口名正确显示，再装 DJI Assistant 2 Consumer 带来的 DJI VCOM 驱动。 
dji-rc-bridge.exe --scan        # find the remote; prints "remote protocol port: COMx"# 找到遥控器，输出"遥控器协议端口: COMx"
dji-rc-bridge.exe --watch       # confirm your sticks and keys arrive# 确认摇杆与按键数据能读到
dji-rc-bridge.exe --calibrate   # capture centres and end-stops# 采集居中值与满行程
dji-rc-bridge.exe --run         # bridging on — now start your game# 桥接开启 — 然后进游戏

The single .exe is self-contained (static CRT). Closing the window or pressing Ctrl+C removes the virtual pad and returns the remote to normal. 单个 .exe 自带运行库（静态 CRT）。关闭窗口或按 Ctrl+C 即移除虚拟手柄并让遥控器恢复正常。

Key mapping按键映射

The remote has four digital keys, one 3-position switch, one wheel and two sticks. Exclusive hold layers make that cover a full gamepad. 遥控器只有 4 个数字键、1 个三段开关、1 个拨轮和 2 个摇杆。靠"互斥长按层"覆盖整只手柄。

  • One wheel becomes both analogue triggers by direction — aim with LT, fire with RT.单个拨轮按方向拆成两个模拟扳机——LT 瞄准、RT 开火。
  • Layers are exclusive: while a modifier is held only that layer is produced, so a press can never fire two actions.长按层互斥：修饰键按住时只输出该层，一次按键绝不会同时触发两个动作。
  • Digital thresholds use linear travel, unaffected by the aiming expo curve. The Xbox/GUIDE button is deliberately unmappable.数字判定基于线性行程，不受瞄准 expo 曲线影响。Xbox/GUIDE 键故意不可映射。

Diagnostics诊断工具

When something does not work, the built-in tools answer "is it the cable, the driver, the protocol or the mapping?" without guesswork: 出问题时，内置工具能直接回答"是线材、驱动、协议还是映射的问题"，不用猜：

  • --scan — probes every candidate port with real DUML instead of trusting port names对每个候选口用真实 DUML 实测，不靠端口名猜
  • --listen / --raw — byte-level truth: is anything coming back at all原始字节层面：到底有没有回话
  • --sweep / --probe / --try / --baudsweep — walk command groups, ids and baud rates遍历命令组、命令号与波特率
  • bridge-tests — offline tests against byte-exact protocol golden vectors, no hardware needed对着逐字节协议黄金样本做离线测试，不需要硬件

The physical power key is a hardware switch, never reported over the protocol, so it cannot be mapped. 物理电源键是硬件开关，协议里不报文，因此无法映射。

Known limitations已知限制

  • Four physical keys: games needing many simultaneous distinct buttons rely on hold layers, or on Steam Input / reWASD above the virtual pad.只有 4 个实体键：需要大量同时按键的游戏要靠长按层，或在虚拟手柄之上再套 Steam Input / reWASD。
  • Undocumented protocol — a firmware update on either side can break it at any time.协议无公开文档，任一侧固件更新都可能随时让它失效。
  • Springs return the sticks to centre, which is what games expect, but the travel is short — fine for third-person and driving, not for competitive FPS.摇杆带回中弹簧，符合手柄预期，但行程较短——第三人称与驾驶合适，竞技 FPS 不建议。
  • Only RC-N1/RC-N3 over the For Protocol interface was verified on hardware. The vendor bulk channels (MI_00/MI_01) are reachable via DJI's own libusb fork but are not implemented.仅在 RC-N1/RC-N3 的 For Protocol 接口上做过真机验证。厂商 bulk 通道（MI_00/MI_01）可通过 DJI 自带的 libusb 分支访问，但本项目未实现。
  • Virtual input devices can look suspicious to anti-cheat. Do not use it in ranked or online competitive play.虚拟输入设备可能被反作弊视为可疑。请勿用于排位或联机竞技。
Safety安全 — never run this while the remote is bound to a powered aircraft. The program only reads input, but a live controller can still transmit. Full terms in —— 严禁在遥控器与已通电航空器保持连接时使用。程序虽只读取输入，但通电的遥控器仍可能发射信号。完整条款见 DISCLAIMER.md.
